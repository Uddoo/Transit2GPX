# 已知限制

最后更新：2026-09-28。

## v1.0 外部验收状态

- 仓库不包含完整 CPTOND-2025 或 Science Data Bank 数据；本机真实包、隔离数据库和验收 GPX 放在被忽略的 `data/` 目录。
- Science Data Bank 的真实 46 城数据已完成整包导入：992 条线路全部通过质量门禁。东莞普通线路与上海环线已核对地图叠加、正反向 edge、环线两候选、candidate digest、保存一致性及 journey/coverage GPX。
- 2026-08-21，用户确认 V1.0 GPX 在实际安装的 Fog of World 中手动导入通过；最后一个外部兼容验收项已经关闭。

## 当前产品边界

- 数据目录使用本机绝对路径输入，尚无原生目录选择器。
- 默认 OpenStreetMap Standard 底图需要联网且属于尽力服务；可关闭底图或改用符合许可与使用政策的自托管瓦片。
- 已提供 Windows 用户级 ZIP 安装目录和 macOS `.pkg`/`.app` 构建流程，但产物尚未做 Authenticode、Apple Developer ID 签名或公证，也不提供 Windows 服务、托盘程序和自动更新。
- CPTOND 是 v1.0 的规范线路基线；Science Data Bank 兼容源基于同一数据并增加开通时序，但采用 CC BY-NC-SA 4.0。实时运营变更、临时停运和新开线路仍需等待新数据版本。
- 后续数据版本或 Fog of World 版本升级仍应重复人工兼容抽检；自动测试覆盖 GPX 1.1 XSD 与几何约束，但不能永久替代第三方应用的版本回归。

## 铁路扩展状态

- 中国铁路、高铁和动车的 R0–R3 实现与自动化门禁已经完成：固定版本 sidecar、长三角/全国真实图、Provider、迁移、车站搜索、候选解释与确认、不可变快照、统一 CSV、混合 GPX、版本比较、显式重算、原子切换和回滚均可运行。
- 2026-08-21，用户确认真实铁路 GPX 已在实际安装的 Fog of World 中手动导入成功；铁路首版最后一个外部验收已关闭。
- 产品已由 Metro2Fog 迁移为 Transit2GPX。新安装使用新名称；旧环境变量、数据库、备份、铁路图元数据和 sidecar 元数据端点仍兼容读取。
- 第一版铁路事实只接受用户手动输入或 CSV；不内置 12306 爬虫，也不永久缓存高德查询结果。
- OSM 的中国铁路属性、车站和 `route=train` 关系可能不完整。系统必须返回候选并要求确认，不能把最高分当作已知真实路径。
- OpenRailRouting 全国图在当前基准机上使用约 1.58 GB PBF、187 MB graph，建图约 166 秒、峰值 RSS 约 1.46 GB；不同 Java、磁盘和 OSM 版本会改变这些数字，不能视为通用最低配置。
- Windows 铁路入口、无符号链接 selector 与失败诊断已有自动测试；2026-08-31 已用项目内 Temurin 21.0.12.1+1 完成 OpenRailRouting 全部 34 项测试、Cologne fixture 建图、路由/metadata smoke 和端口清理。长三角及全国真实图仍需单独留存 Windows 资源与耗时证据，不能直接套用 macOS 基准。
- 省级 PBF 在边界处可能产生裁剪和关系完整性问题；跨省路径进入验收前必须执行合并/保全提取与连通性测试。
- 铁路 coverage 去重第一版只保证同一数据/图版本；跨版本轨道几何变化需要显式审核。
- 仓库不会提交 OSM PBF、graph cache 或全国铁路派生数据库；公开分发这些数据前必须另行履行 ODbL 义务。

铁路实现契约与阶段验收见 [`RAILWAY.md`](RAILWAY.md)。

## 已知非阻断技术债

- 前端已按页面、地图与铁路编辑器拆包，入口约 282 KB，地图运行库按需加载。该数字不代表所有页面的总下载量。
- 后台导入和启动恢复面向默认的单个本地 API 进程，不支持多个 API 实例同时操作同一数据库。
- 完整发布包可内置 sidecar JAR，但由于 PBF/graph 体积和 ODbL 边界，不内置全国图；铁路模式仍要求 Java 17+ 与用户单独准备、验证和激活图数据。
